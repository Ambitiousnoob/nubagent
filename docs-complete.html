🔧 Phase 0: Prerequisites & Project Setup

0.1Prerequisites
What You Need
  • Node.js 18+ (for running locally)
  • npm (comes with Node.js)
  • Git (optional, for cloning)
  • Vercel Account (free tier works)
  • Google Account (for Gemini API - optional but recommended)
  • Facebook Account (for Facebook App - if using Messenger)
Step 0.1.1: Verify Node.js
node --version
# Should output: v18.0.0 or higher

npm --version
# Should output: 9.0.0 or higher

If not installed, download from nodejs.org

Step 0.1.2: Clone the Project
git clone https://github.com/Ambitiousnoob/nubagent.git
cd nubagent

Or download the ZIP and extract it.

Step 0.1.3: Install Dependencies
npm install

Takes ~30 seconds. You should see "145 packages installed".

Step 0.1.4: Create .env File
cp .env.example .env

This creates a local .env file that you'll fill in with your tokens.

✅ Phase 0 Complete - Your project is ready. Now choose your path.

⚡ Phase 1: Gemini API Setup (Chat Endpoint)

This enables the /api/chat endpoint, which powers the AI responses. This is REQUIRED for both chat API and Messenger bot.

1.1Get Google Account
Step 1.1.1: Sign Up for Google Account
  1. Go to accounts.google.com
  2. Click "Create account"
  3. Fill in your details (first name, last name, email)
  4. Create a password
  5. Complete verification (phone or recovery email)

Skip this if you already have a Google account.

1.2Generate Gemini API Key
Step 1.2.1: Go to Google AI Studio
  1. Visit aistudio.google.com/app/apikey
  2. Sign in with your Google account (if not already signed in)
  3. Click "Create API Key" button
Step 1.2.2: Copy Your API Key
  1. A dialog will pop up with your new API key
  2. Click "Copy" to copy it to clipboard
  3. DO NOT SHARE THIS KEY
⚠️ IMPORTANT: Keep this key secret. Anyone with this key can use your Gemini API quota and incur charges (if you have billing enabled).
Step 1.2.3: Add to .env File
  1. Open your .env file in a text editor
  2. Find the line: GEMINI_API_KEY=your_gemini_api_key_here
  3. Replace your_gemini_api_key_here with your actual API key
  4. Save the file
# Example (NOT A REAL KEY)
GEMINI_API_KEY=AIzaSyD_example_key_12345678901234567890
✅ Gemini API Key Added - You can now use the chat endpoint.
1.3Test Locally
Step 1.3.1: Start Development Server
npm run dev

You should see:

VITE v5.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
➜  API:     http://localhost:5173/api/chat
Step 1.3.2: Test Chat API with curl

Open another terminal and run:

curl -X POST http://localhost:5173/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      { "role": "user", "content": "What is 2+2?" }
    ]
  }'

You should get a JSON response with the AI's answer.

✅ Gemini API Working - Your chat endpoint is ready!

💬 Phase 2: Facebook Messenger Setup (Optional)

This enables the /api/webhook endpoint, allowing users to chat via Facebook Messenger. This is optional - you can skip this if you only need the REST API.

2.1Create Facebook App
Step 2.1.1: Go to Meta Developers
  1. Visit developers.facebook.com/apps
  2. Sign in with your Facebook account (or create one)
  3. Click "Create App"
Step 2.1.2: Configure Your App
  1. Select "Business" as app type
  2. Fill in app details:
    • App Name: "NubAgent Messenger" (or any name)
    • Contact Email: Your email
    • App Purpose: "Chat or Messaging"
  3. Click "Create App"
Step 2.1.3: Add Messenger Product
  1. On the app dashboard, click "Add Product"
  2. Find "Messenger" in the list
  3. Click "Set Up"
✅ App Created - Messenger product is ready.
2.2Get Access Tokens
Step 2.2.1: Create or Connect Facebook Page
  1. In Messenger settings, scroll to "Access Tokens"
  2. Click "Add or Remove Pages"
  3. If you don't have a page:
    1. Click "Create New Page"
    2. Fill in page name and category (e.g., "NubAgent Bot")
    3. Complete setup
  4. If you have a page: Select it from the dropdown
Step 2.2.2: Copy Page Access Token
  1. In Access Tokens section, find your page
  2. Click "Generate Token"
  3. A token will appear - click "Copy"
  4. Add to .env file: 
    PAGE_ACCESS_TOKEN=your_copied_token
⚠️ IMPORTANT: This token gives access to your page. Keep it secret.
✅ PAGE_ACCESS_TOKEN Added
2.3Set Up Webhook
Step 2.3.1: Choose a Verify Token

This is any random string you choose (not generated). It's used to verify that webhook requests come from Facebook.

Generate one:

echo $(openssl rand -hex 16)

Or just make up a random string like: my_secret_verify_token_12345

Add to .env file:

VERIFY_TOKEN=my_secret_verify_token_12345
Step 2.3.2: Get Your Webhook URL

You'll need to deploy to Vercel first to get a public URL. For now, write down this template: 

https://your-vercel-deployment.vercel.app/api/webhook

You'll come back to this after deploying.

Step 2.3.3: Register Webhook (After Deployment)

Once you've deployed to Vercel:

  1. Go back to Meta Developers → Your App → Messenger → Settings
  2. Scroll to "Webhooks"
  3. Click "Add Callback URL"
  4. Fill in:
    • Callback URL: https://your-app.vercel.app/api/webhook
    • Verify Token: The token you chose above
  5. Click "Verify and Save"

Facebook will send a GET request to verify. If successful, it will save the webhook.

Step 2.3.4: Subscribe to Events
  1. In Webhooks section, click "Select Events"
  2. Check "messages"
  3. Click "Save"
✅ Webhook Configured - Ready to receive messages.
2.4Subscribe Page to App
Step 2.4.1: Enable Subscription
  1. In Messenger → Settings, scroll to "Webhook"
  2. Find your page in the list
  3. Click "Subscribe"
  4. You should see a checkmark next to your page
✅ Messenger Setup Complete - Your bot is ready to receive messages!

🚀 Phase 3: Deploy to Vercel

3.1Push to GitHub
Step 3.1.1: Initialize Git (if needed)
git init
git add .
git commit -m "Initial NubAgent setup"
Step 3.1.2: Create GitHub Repo
  1. Go to github.com/new
  2. Create repository named "nubagent"
  3. Add remote and push: 
    git remote add origin https://github.com/YOUR_USERNAME/nubagent.git
git branch -M main
git push -u origin main
3.2Deploy to Vercel
Step 3.2.1: Connect Vercel
  1. Go to vercel.com/new
  2. Click "Import Git Repository"
  3. Select your GitHub repo
  4. Click "Import"
Step 3.2.2: Add Environment Variables
  1. In Vercel project settings, go to "Environment Variables"
  2. Add each variable from your .env file:
    • GEMINI_API_KEY = your API key
    • PAGE_ACCESS_TOKEN = your page token (if using Messenger)
    • VERIFY_TOKEN = your verify token (if using Messenger)
  3. Click "Save"
Step 3.2.3: Deploy
  1. Click "Deploy"
  2. Wait for deployment to complete (2-3 minutes)
  3. You'll get a URL like: https://nubagent-abc123.vercel.app
✅ Deployed! Your app is live.
3.3Finalize Messenger Setup (if applicable)
Step 3.3.1: Register Webhook URL

Go back to Phase 2.3.3 and use your Vercel URL: https://your-vercel-app.vercel.app/api/webhook

🔧 Troubleshooting

?Common Issues
Chat API returns 500 "Missing GEMINI_API_KEY"

Fix:

  1. Verify GEMINI_API_KEY is in your .env file
  2. Make sure it's not wrapped in quotes
  3. Restart your dev server: npm run dev
  4. Check you didn't accidentally paste the key with newlines
Messenger webhook returns 403 "Verification failed"

Fix:

  1. Double-check VERIFY_TOKEN in .env matches Meta Developers
  2. Ensure VERIFY_TOKEN is in Vercel environment variables
  3. Redeploy Vercel after adding variables
  4. Try registering webhook again in Meta Developers
Messenger webhook returns 500 "Missing PAGE_ACCESS_TOKEN"

Fix:

  1. Verify PAGE_ACCESS_TOKEN is in Vercel environment variables
  2. Make sure token is complete (very long string)
  3. Regenerate the token in Meta Developers if unsure
  4. Redeploy Vercel
No response from bot after messaging

Fix:

  1. Check that page is subscribed to webhook (check in Meta Developers)
  2. Check that /api/webhook is reachable: 
    curl https://your-vercel-app.vercel.app/api/webhook
    Should return something (not 404)
  3. Check Vercel logs for errors
  4. Verify webhook URL registered correctly
