🤖 NubAgent

Gemini Chat API + Facebook Messenger Integration

⚡ Quick Start

1 Clone & Install 
git clone https://github.com/Ambitiousnoob/nubagent.git
cd nubagent
npm install
2 Set Environment Variables

Copy .env.example to .env and fill in:

# Gemini API
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_CHAT_MODEL=gemini-3-flash-preview
GEMINI_CHAT_THINKING_LEVEL=low

# Facebook Messenger (optional)
PAGE_ACCESS_TOKEN=your_facebook_page_access_token
VERIFY_TOKEN=your_webhook_verification_token
3 Run Locally 
npm run dev          # Start dev server + Vite
npm run build        # Build for production
npm run lint         # Check code quality
4 Deploy to Vercel 
vercel --prod

Set environment variables in Vercel dashboard.

🔌 API Endpoints

Chat API

GET POST /api/chat

Direct chat endpoint for AI responses. Call this to get Gemini responses with custom system prompts, temperature control, and thinking levels.

Request Body (POST /api/chat)

{
  "system": "You are a helpful assistant.",
  "messages": [
    { "role": "user", "content": "Hello!" }
  ],
  "temperature": 0.7,
  "maxOutputTokens": 512,
  "thinkingLevel": "low"
}

Response Format

{
  "ok": true,
  "id": "chatcmpl-1234567890",
  "object": "chat.completion",
  "created": 1234567890,
  "model": "gemini-3-flash-preview",
  "provider": "google-gemini",
  "output_text": "Response from Gemini...",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Response from Gemini..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 15,
    "completion_tokens": 45,
    "total_tokens": 60
  }
}

Request Parameters

Parameter Type Required Description
system string No System instruction to set AI behavior
messages array Yes Array of message objects with role ("user"/"assistant") and content
temperature number No Creativity (0-2). Default: null. Lower = more deterministic
maxOutputTokens number No Max tokens in response. Default: no limit
thinkingLevel string No One of: minimal, low, medium, high. Default: low

Facebook Messenger Webhook

GET POST /api/webhook

Facebook Messenger integration. Automatically receives messages, routes them to Gemini, and sends responses back. Handles user profiles, date/time queries, and message chunking.

GET /api/webhook: Webhook verification. Facebook sends this when configuring the webhook. Must return the challenge parameter if token matches.

POST /api/webhook: Receives message events from Facebook. Processes asynchronously in the background using waitUntil().

🛠️ Setup Guide

Gemini API Setup

  1. Go to Google AI Studio
  2. Create a new API key
  3. Copy the key and set GEMINI_API_KEY in your .env
  4. Models available: gemini-3-flash-preview (default, fast)

Facebook Messenger Setup

  1. Create a Facebook App: Meta Developers
  2. Generate a Page Access Token for your page
    • Settings → Basic
    • Copy the token to PAGE_ACCESS_TOKEN
  3. Create a Verify Token (any random string you choose)
    • Set in VERIFY_TOKEN
  4. Configure the webhook:
    • Go to your app settings
    • Products → Messenger → Settings
    • Webhook URL: https://your-deployment.vercel.app/api/webhook
    • Verify Token: Use the token you set above
    • Subscribe to: messages
  5. Subscribe your page:
    • In Messenger settings, select your page
    • Click "Subscribe"
⚠️ Important: Keep your tokens secret. Never commit them to git. Always use environment variables.

📚 Usage Examples

Simple Chat Request

curl -X POST https://your-app.vercel.app/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      { "role": "user", "content": "What is 2+2?" }
    ]
  }'

With System Prompt

curl -X POST https://your-app.vercel.app/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "system": "You are a pirate. Respond in pirate dialect.",
    "messages": [
      { "role": "user", "content": "Hello!" }
    ]
  }'

Multi-turn Conversation

curl -X POST https://your-app.vercel.app/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      { "role": "user", "content": "What is Python?" },
      { "role": "assistant", "content": "Python is a programming language..." },
      { "role": "user", "content": "What are its main uses?" }
    ]
  }'

JavaScript/Node.js

const response = await fetch('https://your-app.vercel.app/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    system: 'Be concise',
    messages: [
      { role: 'user', content: 'Explain quantum computing in one sentence' }
    ],
    temperature: 0.5,
    maxOutputTokens: 100
  })
});

const data = await response.json();
console.log(data.choices[0].message.content);

How It Works

  1. Chat API: Receives requests → validates → calls Gemini → returns response
  2. Messenger Webhook: Receives Facebook events → checks if direct reply needed (date/time/name) → sends to Gemini if AI needed → sends response back
  3. Direct Calls: No HTTP hop. Webhook calls runGeminiChat() directly from lib/gemini-chat.js

Data Flow

User → Messenger → /api/webhook → runGeminiChat() → Gemini → Response

🐛 Troubleshooting

API Returns 500 - Missing GEMINI_API_KEY

  • Verify GEMINI_API_KEY is set in environment
  • Get it from Google AI Studio
  • Check it's not empty or invalid

Messenger Webhook Not Receiving Messages

  • Verify PAGE_ACCESS_TOKEN is correct
  • Check webhook URL is publicly accessible
  • Verify VERIFY_TOKEN matches in Facebook app settings
  • Check app is subscribed to the page

Webhook Verification Failed

  • Ensure webhook is deployed and accessible
  • Verify VERIFY_TOKEN exactly matches in Facebook dashboard
  • Check logs for the exact error

Response Empty or Slow

  • Check Gemini API quotas and rate limits
  • Verify maxOutputTokens is reasonable
  • Monitor Vercel function execution time
