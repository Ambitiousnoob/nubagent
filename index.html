🤖 NubAgent

Direct AI Access API — Deploy your own Gemini endpoint with Messenger integration

⚡ Get Started

NubAgent provides two endpoints for AI access: a REST API and a Facebook Messenger webhook. No proxies, no middlemen—direct access to Google Gemini.

✅ Live on Vercel: https://nubagent.vercel.app

Quick Setup

git clone https://github.com/Ambitiousnoob/nubagent.git
cd nubagent
npm install
cp .env.example .env
npm run dev

Get your Gemini API key from Google AI Studio and add to .env: 

GEMINI_API_KEY=your_key_here

🔌 Messenger Webhook

POST /api/webhook

POST
GET

Facebook Messenger integration. Users message your Facebook page, and the bot replies automatically with AI responses using Gemini.

Setup Steps

  1. Create a Facebook App & Page
  2. Add webhook URL: https://your-deployment.vercel.app/api/webhook
  3. Set VERIFY_TOKEN to any random string
  4. Set PAGE_ACCESS_TOKEN from your Facebook page
  5. Subscribe to messages and messaging_postbacks

Required Environment Variables

GEMINI_API_KEY=your_api_key
PAGE_ACCESS_TOKEN=your_page_token
VERIFY_TOKEN=your_verify_token

How It Works

1. User messages your Facebook page
2. Webhook receives the message event
3. Calls Gemini directly (no intermediate API)
4. Sends AI response back to user

✨ Features

✓ Direct API Access — POST to /api/chat from anywhere. No signup required, just your own Gemini key.
✓ Messenger Bot — Automatic responses on Facebook. Users message your page, get AI replies instantly.
✓ Direct Function Calls — Messenger webhook calls Gemini directly (no HTTP hops). Fast and efficient.
✓ Production Ready — Deployed on Vercel with auto-scaling, load-balancing, and 99.9% uptime.
✓ OpenAI Compatible — Drop-in replacement for OpenAI chat API clients.
✓ Extended Thinking — Gemini's extended thinking modes (minimal, low, medium, high) for complex reasoning.

🚀 Quick Usage

JavaScript/Node.js

const response = await fetch('https://nubagent.vercel.app/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    messages: [
      { role: 'user', content: 'Explain quantum computing' }
    ],
    temperature: 0.7,
    maxOutputTokens: 256
  })
});

const data = await response.json();
console.log(data.choices[0].message.content);

Python

import requests

response = requests.post(
  'https://nubagent.vercel.app/api/chat',
  headers={'Content-Type': 'application/json'},
  json={
    'messages': [
      {'role': 'user', 'content': 'Hello!'}
    ],
    'temperature': 0.7
  }
)

print(response.json()['choices'][0]['message']['content'])

cURL

curl -X POST https://nubagent.vercel.app/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "What is AI?"}
    ],
    "system": "Be concise.",
    "temperature": 0.5
  }'

🔧 Setup (3 Steps)

1. Add Gemini API Key

  1. Get key: aistudio.google.com
  2. In Vercel dashboard → Settings → Environment Variables
  3. Add: GEMINI_API_KEY=AIza...
  4. Redeploy

2. (Optional) Add Facebook Messenger

  1. Create Meta app: developers.facebook.com
  2. Add Messenger product & get tokens
  3. Add to Vercel: PAGE_ACCESS_TOKEN, VERIFY_TOKEN
  4. Register webhook: https://nubagent.vercel.app/api/webhook
  5. Subscribe to messages

3. Start Using
